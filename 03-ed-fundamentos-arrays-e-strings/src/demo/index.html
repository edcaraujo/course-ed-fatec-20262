Arrays e a Disposição na Memória RAM

Como posições contíguas garantem acesso imediato em tempo constante O(1).

📦 O Princípio da Contiguidade

Um Array é armazenado em um bloco sequencial contínuo de endereços de memória.

Fórmula de Endereçamento:
Endereço(arr[i]) = Base + (i × Tam_Byte)

Como a CPU executa apenas 1 multiplicação e 1 soma aritmética, o acesso indexado arr[i] é estritamente O(1).

⚠️ O Custo do Deslocamento (Shift)

Inserir ou remover itens no início ou meio quebra a contiguidade, exigindo mover todos os itens subsequentes:

  • arr.append(x) / arr.pop(): O(1) (sem deslocamento)
  • arr.insert(0, x) / arr.pop(0): O(N) (desloca N elementos)

🔄 O Segredo do Redimensionamento Amortizado

Quando o buffer atinge a capacidade máxima C:

  1. Aloca um novo bloco com o dobro da capacidade (2C).
  2. Copia os N elementos antigos para o novo endereço (O(N)).
  3. Libera o bloco antigo da memória.

✨ As N inserções baratas O(1) pagam antecipadamente a cópia cara ocasional.

Strings e a Armadilha da Imutabilidade

Por que concatenar strings com + em laços gera complexidade quadrática O(N2).

⚠️ Concatenação Ingênua: O(N2)

Em Python, strings são imutáveis. Fazer s = s + ch aloca uma nova string e copia todos os caracteres anteriores:

Python (Lento)
def concat_bad(words):
    result = ""
    for w in words:
        result = result + w  # Copia tudo de novo! O(N²)
    return result
🚀 A Solução Eficiente: `"".join()` O(N)

Calcula o tamanho total prévio, aloca um único bloco na memória e copia cada pedaço em uma passada:

Python (Ótimo)
def concat_good(words):
    return "".join(words)  # Alocação única! O(N)

Problema: Two Sum II - Array Já Ordenado

Como encontrar o par de elementos sem força bruta e sem memória extra?

LeetCode #167 Médio / Fácil
Tópico: Two Pointers Convergentes
Dado um array de inteiros numbers que já está ordenado em ordem crescente, encontre dois números que somem exatamente o valor target. Retorne os índices dos dois números.
Exemplo: numbers = [2, 7, 11, 15], target = 9
Saída: [0, 1] (ou [1, 2] em 1-based) → pois numbers[0] + numbers[1] = 2 + 7 = 9.
💬 Ponto de Discussão para a Turma:
1. A força bruta com dois laços aninhados testa todos os pares com custo O(N2).
2. Uma tabela hash (dicionário) resolveria em O(N) tempo, mas consumiria O(N) de memória auxiliar.
3. Pergunta: Como podemos aproveitar que o vetor já vem ordenado para resolver com tempo linear O(N) e espaço estritamente constante O(1)?
Técnica & Solução

Técnica: Dois Ponteiros Convergentes

Solução ótima em O(N) tempo e O(1) espaço auxiliar.

💡 A Lógica Determinística

Posicionamos left = 0 no menor valor e right = N - 1 no maior valor:

  • Se nums[left] + nums[right] == target: Par encontrado!
  • Se soma < target: Precisamos de soma maior → avança left += 1.
  • Se soma > target: Precisamos de soma menor → recua right -= 1.
Python • O(N) Tempo / O(1) Espaço
def two_sum_sorted(nums, target):
    left, right = 0, len(nums) - 1
    while left < right:
        current_sum = nums[left] + nums[right]
        if current_sum == target:
            return (left, right)
        elif current_sum < target:
            left += 1
        else:
            right -= 1
    return None

Ponteiro Direito (`right`):
Índice 7 (Valor: 20)
Soma Atual vs Target:
1 + 20 = 21 (> 13)

Problema: Remover Duplicatas de Vetor Ordenado

Como modificar o array in-place sem alocar listas extras e sem custo de shift O(N2)?

LeetCode #26 Fácil
Tópico: Dois Ponteiros In-Place
Dado um array de inteiros ordenado nums, remova os elementos duplicados in-place de forma que cada elemento único apareça apenas uma vez. Retorne o novo comprimento k. O prefixo nums[0...k-1] deve conter os elementos únicos.
Exemplo: nums = [1, 1, 2, 2, 3]
Saída: Retorna 3, e os primeiros 3 elementos de nums passam a ser [1, 2, 3].
💬 Ponto de Discussão para a Turma:
1. Se usássemos nums.pop(i) a cada elemento repetido, cada remoção deslocaria os elementos à direita (custo O(N) por remoção), resultando em O(N2)!
2. Se usássemos set(nums), gastaríamos O(N) de memória auxiliar.
3. Pergunta: Como usar dois ponteiros na mesma direção para sobrescrever o próprio array em tempo O(N) e memória O(1)?
Técnica & Solução

Técnica: Dois Ponteiros Rápido e Lento (In-Place)

Sobrescrevendo posições no próprio vetor sem criar estruturas intermediárias.

📝 LeetCode #26: Remover Duplicados

O ponteiro slow marca o último elemento único confirmado. O ponteiro fast busca novidades:

Python O(N) Tempo / O(1) Espaço
def remove_duplicates(nums):
    if not nums: return 0
    slow = 0
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]  # Grava elemento
    return slow + 1
🔄 LeetCode #283: Mover Zeros

Agrupa todos os elementos diferentes de zero à esquerda e empurra os zeros para a direita:

Python O(N) Tempo / O(1) Espaço
def move_zeroes(nums):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow], nums[fast] = nums[fast], nums[slow]
            slow += 1
    return nums

Problema: Subarray de Tamanho Fixo com Maior Média

Como evitar recalcular somas de fatias contíguas do zero?

LeetCode #643 Fácil
Tópico: Janela Deslizante Fixa
Dado um array nums composto por n inteiros e um inteiro k, encontre um subarray contíguo de tamanho exatamente k que possua a maior média de valor e retorne esse valor.
Exemplo: nums = [1, 12, -5, -6, 50, 3], k = 4
• Janela 1: [1, 12, -5, -6] → Soma = 2
• Janela 2: [12, -5, -6, 50] → Soma = 51 ⭐ → Média = 51 / 4 = 12.75
💬 Ponto de Discussão para a Turma:
1. Fazer um laço de tamanho K para cada uma das (N − K) posições custaria O(N × K).
2. Pergunta: Ao mover a janela 1 posição para o lado, quais elementos realmente mudam na soma total? Como fazer essa transição em tempo constante O(1)?
Técnica & Solução

Técnica: Janela Deslizante de Tamanho Fixo

Atualização do estado da janela em O(1) por deslocamento (+ novo, − antigo).

🪟 Transição em Tempo Constante

Calculamos a primeira janela de tamanho K. Para cada passo subsequente:

+ Entra elemento da direita (nums[right])
− Sai elemento da esquerda (nums[left])

A complexidade total cai de O(N × K) para O(N)!

Python • O(N) Tempo / O(1) Espaço
def find_max_average(nums, k):
    window_sum = sum(nums[:k])
    max_sum = window_sum
    for right in range(k, len(nums)):
        left = right - k
        window_sum += nums[right] - nums[left]
        if window_sum > max_sum:
            max_sum = window_sum
    return max_sum / k

Janela Atual [L ... R]:
[ 2, 1, 5 ]
Cálculo O(1) da Transição:
Soma Inicial: 8
Soma Máxima Encontrada:
Max = 8

Problema: Menor Subarray com Soma ≥ S

Como encontrar o tamanho ótimo quando o comprimento da janela é variável?

LeetCode #209 Médio
Tópico: Janela Deslizante Dinâmica
Dado um array de inteiros positivos nums e um inteiro positivo target, retorne o comprimento mínimo de um subarray contíguo cuja soma seja maior ou igual a target. Se não existir, retorne 0.
Exemplo: target = 7, nums = [2, 3, 1, 2, 4, 3]
• Subarray [2, 3, 1, 2] tem soma 8 ≥ 7 (tam 4)
• Subarray [4, 3] tem soma 7 ≥ 7 (tam 2) ⭐ → Resposta: 2.
💬 Ponto de Discussão para a Turma:
1. Como o tamanho da janela não é fixo, testar todas as combinações de início e fim custaria O(N2).
2. Pergunta: Como expandir a borda direita até bater a meta e encolher a borda esquerda para encontrar o menor tamanho possível em tempo linear O(N)?
Técnica & Solução

Técnica: Janela Deslizante Dinâmica (Expand & Shrink)

Controle coordenado de duas bordas com análise amortizada O(N).

📏 Mecânica do Expand & Shrink

1. Expandir: Avança right adicionando elementos até que a condição seja satisfeita (current_sum ≥ target).

2. Encolher: Enquanto a condição for válida, tenta avançar left para minimizar a janela.

⚡ Como left e right avançam no máximo N vezes cada, o tempo total é estritamente O(N).

Python O(N) Tempo / O(1) Espaço
def min_subarray_len(target, nums):
    left, current_sum = 0, 0
    min_len = float('inf')
    
    for right in range(len(nums)):
        current_sum += nums[right]  # Expande
        
        while current_sum >= target:  # Encolhe
            min_len = min(min_len, right - left + 1)
            current_sum -= nums[left]
            left += 1
            
    return min_len if min_len != float('inf') else 0

Problema: Consultas de Soma de Intervalo (Range Sum)

Como responder a milhares de perguntas de soma de fatias em tempo instantâneo O(1)?

LeetCode #303 Fácil
Tópico: Prefix Sum (Soma de Prefixos)
Dado um array de inteiros nums, responda a múltiplas consultas de soma do intervalo [L, R], calculando a soma dos elementos de nums[L] até nums[R] inclusive.
Cenário de Escala: Array com N = 100.000 elementos e Q = 100.000 consultas.
• Se cada consulta fizer um loop de L até R → Custo total: O(Q × N) = 10.000.000.000 operações (→ Time Limit Exceeded!).
💬 Ponto de Discussão para a Turma:
1. Podemos gastar um pré-processamento inicial de O(N) para acumular as somas.
2. Pergunta: Como usar essa tabela acumulada para responder a qualquer consulta em uma única subtração aritmética de tempo O(1)?
Técnica & Solução

Técnica: Vetor de Soma de Prefixos (Prefix Sum)

Consultas de intervalo respondidas em O(1) através da fórmula P[R] − P[L−1].

⚡ A Dedução da Fórmula

Construímos o vetor acumulado: P[i] = P[i-1] + nums[i].

Soma(L, R) = P[R] − P[L − 1]   (se L > 0)
Soma(0, R) = P[R]   (se L = 0)

Total para Q consultas: O(N + Q) em vez de O(Q × N)!

Python • LeetCode #303
class NumArray:
    def __init__(self, nums: list[int]):
        self.prefix = [0] * len(nums)
        if nums:
            self.prefix[0] = nums[0]
            for i in range(1, len(nums)):
                self.prefix[i] = self.prefix[i - 1] + nums[i]
                
    def sumRange(self, left: int, right: int) -> int:
        if left == 0: return self.prefix[right]
        return self.prefix[right] - self.prefix[left - 1]

Problema: Verificação de Palíndromo

Como validar palíndromos com pontuação sem gastar memória alocando novas strings?

LeetCode #125 Fácil
Tópico: Strings & Dois Ponteiros In-Place
Uma frase é um palíndromo se, após converter maiúsculas em minúsculas e remover caracteres não-alfanuméricos, ela for lida da mesma forma para frente e para trás.
Exemplo 1: s = "A man, a plan, a canal: Panama" → Retorna True
Exemplo 2: s = "race a car" → Retorna False
💬 Ponto de Discussão para a Turma:
1. Criar uma nova string filtrada na memória consome O(N) de memória auxiliar.
2. Pergunta: Como usar dois ponteiros opostos que pulam espaços e pontuações na string original para alcançar O(N) de tempo e estritamente O(1) de memória?
Técnica & Solução

Técnica: Palíndromos com Dois Ponteiros In-Place

Validação com memória auxiliar O(1) pulando caracteres não-alfanuméricos.

🛡️ Ponteiros Opostos com `isalnum()`

O ponteiro left avança enquanto não for letra/dígito, e right recua enquanto não for letra/dígito.

Comparamos os caracteres em minúsculo s[left].lower() == s[right].lower() sem alocar nenhuma string auxiliar na RAM!

Python • LeetCode #125 O(N) Tempo / O(1) Espaço
def is_palindrome(s: str) -> bool:
    left, right = 0, len(s) - 1
    while left < right:
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1
            
        if s[left].lower() != s[right].lower():
            return False
        left += 1
        right -= 1
    return True

Problema: Verificação de Anagramas

Qual é a forma mais eficiente de validar se duas palavras têm exatamente as mesmas letras?

LeetCode #242 Fácil
Tópico: Contagem de Frequência
Dadas duas strings s e t, retorne true se t for um anagrama de s, e false caso contrário. Um anagrama usa todas as letras originais exatamente o mesmo número de vezes.
Exemplo 1: s = "anagram", t = "nagaram" → Retorna True
Exemplo 2: s = "rat", t = "car" → Retorna False
💬 Ponto de Discussão para a Turma:
1. Abordagem por Ordenação: sorted(s) == sorted(t) custa O(N log N) em tempo e O(N) em espaço.
2. Pergunta: Como usar um vetor ou dicionário de frequências para atingir tempo estritamente linear O(N)?
Técnica & Solução

Técnica: Anagramas com Histograma de Frequência

Contagem linear em O(N) tempo e O(1) espaço (alfabeto limitado).

Python • LeetCode #242 O(N) Tempo
def is_anagram(s: str, t: str) -> bool:
    if len(s) != len(t): return False
    counts = {}
    for ch in s: counts[ch] = counts.get(ch, 0) + 1
    for ch in t:
        if ch not in counts or counts[ch] == 0:
            return False
        counts[ch] -= 1
    return True
📊 Por que Contagem é Superior?

1. Uma passada em s incrementa as contagens (+1).

2. Uma passada em t decrementa as contagens (−1).

Tempo total: O(N) vs O(N log N) do sorted!

Resumo dos Pontos-Chave 💡

Checklist de sobrevivência e boas práticas para Arrays e Strings.

💡 Resumo dos Pontos-Chave
  • 1. Cuidado com o fatiamento: s[a:b] gera uma nova cópia em memória (O(b − a)).
  • 2. Evite + em strings dentro de laços: Use listas e finalize com "".join() para garantir O(N).
  • 3. Evite insert(0) e pop(0) em listas: O deslocamento (shift) custa O(N). Use collections.deque para O(1).
  • 4. item in list é O(N): Para buscas instantâneas O(1), converta para set ou dict.
  • 5. Two Pointers e Sliding Window: Transformam loops aninhados O(N2) em passagens lineares O(N).
  • 6. Prefix Sum: Reduz o custo de consultas acumuladas repetidas para tempo constante O(1).
