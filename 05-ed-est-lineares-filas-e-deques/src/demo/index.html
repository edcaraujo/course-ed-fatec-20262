Fundamentos

O Conceito de Fila e o Princípio FIFO

A ordem de chegada governa a ordem de atendimento: o primeiro a entrar é o primeiro a sair.

🚶‍♂️ Princípio FIFO (First-In, First-Out)

Uma Fila (Queue) é uma estrutura de dados linear e justa que opera com duas extremidades distintas:

  • Início / Frente (Front): Onde os elementos são consultados e removidos (Dequeue).
  • Fim / Cauda (Rear): Onde novos elementos chegam e são inseridos (Enqueue).
  • Analogias: Fila do caixa de banco, túnel de pedágio, fila de impressão (*print spooler*).
💻 Aplicações Cruciais na Computação
  • Escalonamento de CPU: O escalonador do SO mantém uma fila de processos prontos para execução.
  • Sistemas de Mensageria: RabbitMQ, Kafka e SQS como filas corporativas assíncronas.
  • Roteadores e Redes: Buffers de pacotes IP para controle de congestionamento.
  • Algoritmos de Grafos: A Busca em Largura (BFS - Breadth-First Search) utiliza filas FIFO.
Operações & Complexidade

Operações Primitivas do TAD Fila

Tempo estrito O(1) nas duas extremidades sem deslocamento de memória.

⚡ Primitivas do TAD Fila
Operação Efeito Custo Ideal
enqueue(x) Insere item x no final da fila O(1)
dequeue() Remove e retorna o item do início O(1)
front() / peek() Consulta o item da frente sem remover O(1)
is_empty() Verifica se a fila está vazia O(1)
size() Retorna contagem total de itens O(1)
⚠️ Estados de Erro e Exceções
Queue Underflow:
Tentativa de executar dequeue() ou front() em uma fila vazia. Dispara IndexError.
Queue Overflow:
Tentativa de executar enqueue() em um buffer com capacidade esgotada.

Performance em Python

A Grande Armadilha do list.pop(0)

Por que usar uma lista comum como fila degrada catastrophicamente seu software.

🚨 O Deslocamento O(N) na RAM

Uma list em Python é um array contíguo de ponteiros em C. Ao executar fila.pop(0):

  • O primeiro item é removido do índice 0.
  • Todos os $N-1$ elementos restantes são deslocados uma posição para a esquerda para cobrir o buraco!
  • Isso exige $N-1$ operações de cópia de ponteiros na memória a CADA dequeue.
Para 100.000 requisições: 100.000 × 50.000 = ~5 bilhões de operações inúteis de cópia!
⚖️ Comparação de Tempo Real
Operação list.pop(0) Fila Circular / Deque
10.000 dequeues ~0.045 s ~0.001 s (45x mais rápido)
100.000 dequeues ~4.820 s ~0.012 s (400x mais rápido)
1.000.000 dequeues Trava / Minutos ~0.120 s
Engenharia de Algoritmos

Buffer Circular: Aritmética Modular

Como garantir O(1) estrito em arrays contíguos sem deslocar memória.

🔄 A Lógica do Módulo (%)

Em vez de mover os elementos para a esquerda, movemos os ponteiros de índice:

# Avanço circular dos índices:
self._fim = (self._fim + 1) % self._capacidade
self._inicio = (self._inicio + 1) % self._capacidade

Quando o índice alcança a capacidade máxima $C$, a operação módulo faz o índice voltar ao índice $0$ aproveitando os espaços já desocupados!

💡 Vantagens da Fila Circular
  • Zero Deslocamentos: Elementos permanecem imóveis na memória física até serem substituídos.
  • Localidade de Cache Máxima: Utiliza um array contíguo em RAM, altamente amigável para o hardware da CPU.
  • Uso Extensivo na Indústria: Buffers de áudio/vídeo, drivers de rede e ring buffers do kernel Linux.
Implementação Autossuficiente

Nossa Classe Fila Circular em Python

Pronta para copiar e colar em qualquer problema ou juiz online sem imports.

📦 Código Limpo e Autossuficiente
class Fila:
    def __init__(self, capacidade: int = 100):
        self._capacidade = capacidade
        self._elementos = [None] * capacidade
        self._inicio = 0
        self._fim = 0
        self._tamanho = 0

    def enqueue(self, item):
        if self._tamanho == self._capacidade:
            raise OverflowError("Queue Overflow!")
        self._elementos[self._fim] = item
        self._fim = (self._fim + 1) % self._capacidade
        self._tamanho += 1

    def dequeue(self):
        if self.is_empty():
            raise IndexError("Queue Underflow!")
        item = self._elementos[self._inicio]
        self._elementos[self._inicio] = None
        self._inicio = (self._inicio + 1) % self._capacidade
        self._tamanho -= 1
        return item
📊 Métodos Auxiliares
    def front(self):
        if self.is_empty():
            raise IndexError("Queue Underflow!")
        return self._elementos[self._inicio]

    def is_empty(self) -> bool:
        return self._tamanho == 0

    def size(self) -> int:
        return self._tamanho

    def __len__(self) -> int:
        return self._tamanho

Totalmente blindada contra operações inválidas no meio da fila e com tempo estrito O(1).

Arquitetura de Dados

Fila Encadeada: Ponteiros Head e Tail

Crescimento dinâmico sob demanda na memória Heap sem capacidade pré-alocada.

🔗 Implementação com Nós
class Node:
    def __init__(self, dado):
        self.dado = dado
        self.proximo = None

class FilaEncadeada:
    def __init__(self):
        self._head = None  # Dequeue aqui
        self._tail = None  # Enqueue aqui
        self._tamanho = 0

    def enqueue(self, item):
        novo = Node(item)
        if not self._tail:
            self._head = self._tail = novo
        else:
            self._tail.proximo = novo
            self._tail = novo
        self._tamanho += 1
⚖️ Buffer Circular vs Fila Encadeada
Critério Buffer Circular Fila Encadeada
Enqueue / Dequeue O(1) O(1)
Capacidade Fixa (ou redimensionável) Dinâmica ilimitada
Overhead RAM Mínimo (apenas array) Ponteiros por nó
Superestrutura Linear

Deques: Double-Ended Queues

A unificação de Pilhas e Filas com acesso simultâneo O(1) em ambas as pontas.

🔄 O que é um Deque?

Um Deque permite inserções, remoções e inspeções em ambas as extremidades:

  • append_front() e pop_front() no Início.
  • append_rear() e pop_rear() no Fim.
  • Se usarmos apenas um lado: comporta-se como uma Pilha (LIFO).
  • Se usarmos lados opostos: comporta-se como uma Fila (FIFO).
⚡ O Padrão Python: collections.deque
from collections import deque

d = deque()
d.append(10)       # Inserir no fim
d.appendleft(20)   # Inserir no início
item = d.popleft() # Remover do início
final = d.pop()    # Remover do fim

Implementado em C como uma lista duplamente encadeada de blocos de 64 itens. Garante O(1) estrito!

Nossa Classe Deque em Python

Lista Duplamente Encadeada garantindo O(1) estrito em todas as 4 extremidades.

🐍 Implementação com Nós Duplos O(1)
class Node:
    def __init__(self, dado, ant=None, prox=None):
        self.dado, self.ant, self.prox = dado, ant, prox

class Deque:
    def __init__(self):
        self._head = self._tail = None
        self._tamanho = 0

    def append_front(self, item):  # O(1) estrito
        novo = Node(item, prox=self._head)
        if not self._head: self._head = self._tail = novo
        else: self._head.ant = novo; self._head = novo
        self._tamanho += 1

    def append_rear(self, item):   # O(1) estrito
        novo = Node(item, ant=self._tail)
        if not self._tail: self._head = self._tail = novo
        else: self._tail.prox = novo; self._tail = novo
        self._tamanho += 1

    def pop_front(self):           # O(1) estrito
        if not self._head: raise IndexError("Vazio!")
        val = self._head.dado
        self._head = self._head.prox
        if not self._head: self._tail = None
        else: self._head.ant = None
        self._tamanho -= 1
        return val

    def pop_rear(self):            # O(1) estrito
        if not self._tail: raise IndexError("Vazio!")
        val = self._tail.dado
        self._tail = self._tail.ant
        if not self._tail: self._head = None
        else: self._tail.prox = None
        self._tamanho -= 1
        return val
💡 Por que NÃO usar list com insert(0)/pop(0)?

Se usássemos list comum:

  • insert(0, x) e pop(0) custam O(N) por mover toda a memória RAM.
  • Isso destruiria a promessa assintótica do TAD Deque!

Com Lista Duplamente Encadeada:

Apenas 2 ou 3 atualizações de ponteiros são feitas, garantindo O(1) puro e real sem nenhum deslocamento.

Simulação de Atendimento em Fila de Banco

Teoria das Filas e modelagem de eventos discretos na tomada de decisões.

🏦 O Cenário Real

Clientes chegam ao banco em instantes aleatórios de tempo. Cada cliente necessita de $D$ minutos no guichê.

  • Uma única fila organizada por ordem de chegada (FIFO).
  • Um ou mais caixas atendem o cliente da frente assim que ficam desocupados.
  • Métrica Principal: Tempo médio de espera na fila!
⚙️ Regra de Transição Temporal
inicio = max(tempo_chegada, caixa_livre)
espera = inicio - tempo_chegada
caixa_livre = inicio + duracao_servico

Se o cliente chega e o caixa já está vago, espera é 0. Caso contrário, ele aguarda o caixa terminar.

Aplicação Prática 2

Escalonamento de Processos: Round-Robin

Como o kernel do Sistema Operacional compartilha o núcleo de processador entre múltiplos programas.

⏱️ O Conceito de Quantum

O Round-Robin (RR) é um algoritmo de escalonamento preemptivo baseado em fila FIFO:

  • Cada processo recebe uma fatia de tempo ininterrupto chamada Quantum ($q$).
  • O processo roda na CPU por até $q$ milissegundos.
  • Se não terminar, é preempcionado (interrompido) e reenfileirado no final da fila de prontos.
  • Se terminar antes ou igual a $q$, ele finaliza e sai do sistema.
🛡️ Por que Round-Robin é Justo?

Impede que um processo longo monopolize a CPU (evita o problema de *Starvation* / Inanição).

Garante tempo de resposta ágil para sistemas interativos e de janelas gráficas.

Aplicação Prática 3

Verificação de Palíndromos com Deque

Comparações simétricas em tempo O(N) sem alocação de strings invertidas.

🎯 Algoritmo com Deque
from collections import deque

def eh_palindromo(texto: str) -> bool:
    d = deque()
    for ch in texto.lower():
        if ch.isalnum():
            d.append(ch)

    while len(d) > 1:
        if d.popleft() != d.pop():
            return False

    return True
🔍 Rastreamento: "radar"
Passo popleft() pop() Comparação
1 'r' 'r' 'r' == 'r' ✅
2 'a' 'a' 'a' == 'a' ✅
3 Resta apenas 'd' (tamanho 1) → Palíndromo!
Aplicação Prática 4

O Jogo da Batata Quente (Josephus)

Como modelar círculos dinâmicos através da circulação na fila.

🔄 Circulação Contínua

Para simular uma roda:

  • Desenfileira da frente: p = fila.popleft().
  • Reenfileira no final: fila.append(p).
  • Após $K$ rotações, quem está na frente é eliminado com fila.popleft()!
  • O processo se repete até restar apenas 1 sobrevivente.
🐍 Código em Python
def batata_quente(nomes, k):
    fila = deque(nomes)
    while len(fila) > 1:
        for _ in range(k):
            fila.append(fila.popleft())
        eliminado = fila.popleft()
    return fila.popleft() # Vencedor
Desafio Técnico

🎯 Fila com Duas Pilhas (LeetCode #232)

A matemática da inversão dupla: duas operações LIFO resultam em FIFO!

📦 Código: Fila com Duas Pilhas
class FilaComPilhas:
    def __init__(self):
        self.entrada = []
        self.saida = []

    def push(self, x: int) -> None:
        self.entrada.append(x)

    def pop(self) -> int:
        self._despejar()
        return self.saida.pop()

    def _despejar(self):
        if not self.saida:
            while self.entrada:
                self.saida.append(self.entrada.pop())
💡 Por que é O(1) Amortizado?

Cada elemento passa por exatamente:

  • 1 push na pilha de entrada.
  • 1 pop na pilha de entrada.
  • 1 push na pilha de saída.
  • 1 pop na pilha de saída.

Cada item é tocado no máximo 4 vezes em toda sua existência. Custo médio por item: $O(1)$ amortizado!

🔍 Para ir além: Concorrência e Tipagem

Filas seguras para múltiplas threads e checagem estática com Generic[T].

🧵 Filas Concorrentes com queue.Queue

Para sistemas multi-threaded onde várias threads consomem simultaneamente:

import queue

q = queue.Queue(maxsize=10)
q.put("Tarefa")   # Bloqueia se cheia
item = q.get()    # Bloqueia se vazia
q.task_done()

Garante exclusão mútua (Thread-Safety) com travas e semáforos.

📦 Tipagem Estática: Generic[T]
from typing import Generic, TypeVar

T = TypeVar('T')

class FilaGenerica(Generic[T]):
    def __init__(self) -> None:
        self._elementos: list[T] = []

    def enqueue(self, item: T) -> None:
        self._elementos.append(item)

Permite validação de tipos em tempo de edição pelo mypy.

Resumo dos Pontos-Chave 💡

Conceitos fundamentais para guardar desta aula.

  • FIFO é a Regra: O primeiro que entra é o primeiro a sair. Inserção no fim, remoção no início.
  • Fuja do list.pop(0): Custa O(N) e degrada a aplicação com cópias contínuas de memória.
  • Buffer Circular: Aritmética modular (i + 1) % C atinge O(1) em arrays estáticos.
  • Deques Unificam Tudo: Permitem inserção e remoção nas duas pontas em O(1).
  • Padrão da Indústria: Em Python, use collections.deque para altíssimo throughput.
  • Aplicações Reais: Modelagem de simulação bancária e escalonadores de CPU (Round-Robin).
